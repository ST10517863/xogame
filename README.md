**XO Game**
I have designed the XO game that allows two players to play together. The app then proceeds to pinpoint the winner once one of the players have 3 matching sets.This only occurs once all the boxes have been filled in by both players. 
The users are required to put in their names in the game for example "Player 1" and "Player 2".
